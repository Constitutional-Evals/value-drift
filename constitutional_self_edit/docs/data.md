# Fixed prompt bank and exploratory measurements

The pilot uses `data/train.jsonl` (1,500 user requests) and `data/eval.jsonl` (120 separate user requests). Each row contains `id`, `prompt`, `category`, `source` (dataset, observed repository revision, split, zero-based source row, first turn, file, access route), and keyword-derived `value_tags`. Only `prompt` belongs in model input. Source metadata and evaluation annotations are researcher-side information.

Training has 600 general, 450 naturalistic, and 450 value-relevant requests. Evaluation has 40 general, 30 naturalistic, and 50 value-relevant requests. The value-relevant held-out slice is selected first with at least three keyword-tagged examples for each of the nine retrieval themes; the remaining slots retain deterministic candidate order. The manifest records actual source counts, tag counts, filters, candidate frame, seed, and creation time. Categories are curation strata, and keyword tags are broad retrieval aids rather than validated labels of the moral content of each prompt.

## Primary sources and terms inspected

- [NVIDIA HelpSteer2](https://huggingface.co/datasets/nvidia/HelpSteer2), accessible without gating, CC-BY-4.0. Its schema has `prompt`, `response`, and five ratings. The `prompt` field sometimes serializes prior assistant turns using `<extra_id_1>Assistant`. We therefore retain only the initial user span before the first role delimiter from revision-pinned `train.jsonl.gz`; duplicate prompts from response pairs count once. A regression test protects this schema detail. Attribution: NVIDIA and the HelpSteer2 contributors.
- [Allen AI WildChat-1M](https://huggingface.co/datasets/allenai/WildChat-1M), accessible without gating, [ODC-By license](https://huggingface.co/datasets/allenai/WildChat-1M/blob/main/LICENSE.md). The card describes this version as excluding conversations flagged as toxic and documents a later removal of flagged sensitive examples. The database license does not independently license all rights in individual contents. We consume only the initial user message; no IP hashes, locations, timestamps, headers, model replies, or moderation labels are stored in curated rows. Attribution: Allen Institute for AI and the WildChat contributors.
- [Anthropic HH-RLHF](https://huggingface.co/datasets/Anthropic/hh-rlhf), accessible without gating, MIT. Only `helpful-base/train.jsonl.gz` is used. The source has complete `chosen` and `rejected` conversations; extraction requires identical first Human spans in both branches and retains that span alone. We never use which branch was preferred, any response, or any label as a target. The card warns against directly training dialogue models on its supplied dialogue responses; those responses are absent from this bank. Attribution: Anthropic and the HH-RLHF contributors.
- [GAIR LIMA](https://huggingface.co/datasets/GAIR/lima) was inspected but not used: it requires agreeing to contact sharing and lists CC-BY-NC-SA or stricter original-source terms. No new access agreement was accepted.

These are local research artifacts. Neither prompts nor generated checkpoints were publicly uploaded as part of curation. Dataset cards and license pages were checked on 2026-09-15; repository revisions are recorded in the manifest. Source metadata can be revisited for any later distribution decision.

## Selection and quality rules

The first user message is extracted from each conversation, preserving its original text apart from surrounding whitespace. Later turns are excluded even when they appear useful, because their interpretation can depend on a dataset assistant response. No original assistant response or preference rating is present in either split. User-supplied quotes and text within the first user message remain user input.

HelpSteer2 and HH inputs are read from revision-pinned gzip JSONL files. The naturalistic frame is the first 6,000 rows of the first original WildChat parquet shard, downloaded at its pinned repository revision; original shard-row indices and conversation hashes are retained. An initial dataset-viewer `/filter` attempt returned inconsistent row identifiers; direct viewer pages then encountered rate limits. Both provisional attempts were discarded before any trajectory. The final bank uses the original revision-pinned parquet file and has no viewer-index ambiguity. All original parquet response and personal-metadata fields are discarded during extraction, and only the first user span and source identifiers are saved.


Candidates use a fixed seed, 20260915, and bounded per-stratum pools. First-user requests must contain 7–320 whitespace words, at most 2,400 characters, at least 55% ASCII letters, exclude CJK scripts and Unicode replacement characters, and be classified as English by `langid` with normalized confidence at least 0.8. This favors relatively short prose and underrepresents code, mathematics, and mixed-language requests. Regex filters exclude obvious fragments, missing referenced material, image/upload dependencies, URLs, emails, phone-like strings, street addresses, explicit personal birth/contact-detail phrases, exposed credential patterns, and explicit adversarial/sexual requests. Filtering is deliberately conservative and imperfect; it does not certify absence of all sensitive content. The open WildChat variant already excludes source-flagged toxic conversations, further limiting refusal-heavy material.

Cross-source deduplication uses Unicode NFKC normalization, case folding, extraction of word characters, and collapsed spaces. Exact normalized duplicates are removed before splitting. Within buckets sharing the first four normalized words, candidates with a word-length difference below 12% and a word-sequence similarity above 0.92 are also excluded as obvious near-duplicates. This narrow rule catches repeated templates without claiming full semantic deduplication. This does not establish semantic independence or absence of benchmark/pretraining contamination. No evaluation input was used as an OCT training input.

The source prompt banks are frozen before any trajectory. `scripts/curate_data.py` refuses to overwrite an existing manifest unless explicitly invoked with `--replace-before-trajectory`; that switch is only for pre-run engineering. Reuse saved artifacts during and after a trajectory. For a lower-cost pilot, call `select_stratified_subset(rows, size)` before the first review, save the exact selected rows in the run directory, and record the size and IDs in run configuration. Never change the selected subset between rounds.

Reproduction dependencies: `requests`, `langid`, `pyarrow`, Python standard library. Run `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python scripts/curate_data.py`. No Hugging Face token or paid API was needed.

## Measurement conventions

`recursive_oct.measurement` provides normalized word-level Levenshtein distance with Python `str.split()` tokens. Case and punctuation remain significant: “kind.” and “kind!” differ by one token; whitespace-only changes have distance zero. The denominator is the maximum of the two word counts and one. Metrics include raw distance, normalized distance from the preceding constitution, normalized distance from the initial constitution, and word count. These descriptive distances are never stopping thresholds; convergence depends on the editing tool history.

Every checkpoint receives the same evaluation system message, `You are a helpful assistant.`, and the same held-out user prompts. Do not include the constitution, research framing, or rubric. Keep generation settings and truncation policy fixed, and save raw responses with prompt IDs. The behavior rubric is saved in `data/behavior_rubric.json`; it independently assesses task helpfulness, honesty, compassion, autonomy, fairness, deference, uncertainty, willingness to disagree, and privacy on explicitly anchored 0–2 scales, allowing null when inapplicable. Deference is descriptive; a higher value is not necessarily desirable. There is no scalar alignment score.

`blind_response_pairs` returns order-randomized anonymous A/B response pairs and a separate researcher-only key. Keep the key and checkpoint order away from a judge. Fix the judge and rubric before rating a trajectory, cite response evidence, and report missing/truncated responses and applicability. Differences can reflect style, length, generation variability, factual quality, and subjective judgments rather than stable changes in values. This small exploratory evaluation cannot establish general alignment or behavioral convergence.
