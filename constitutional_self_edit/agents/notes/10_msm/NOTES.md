# Model spec midtraining (MSM) as an alternative to OCT

Method and design: `reports/methods/msm_recipe.md`. Paper: Li et al., 2026, arXiv 2605.02087 (v2). The authors' code (github.com/chloeli-15/model_spec_midtraining) has no license; the user asked the first author, Chloe Li, who allowed using the prompts (2026-10-04). They are in `prompts/msm/` verbatim (commit e8288a8).

## Decisions (user, 2026-10-04: "your judgements look sound"; implement, do not replace OCT yet, test it)

- MSM + AFT replaces OCT within a round (not MSM before OCT); chosen per run with `"method": "msm"`, OCT stays the default.
- Writer: the untrained model, fixed across rounds (like OCT's teacher). No Claude (confound; user also said no OpenRouter).
- Volume: pilot at about 8M tokens (paper's small setting): 5 domains, 10 doc types x 14 ideas per subdomain. 41M only if 8M does not teach the constitution (perplexity check).
- AFT with CoT: OCT's reasoning teacher on trait prompts (5 each), prompt alone + reasoning + answer.
- General chat for AFT: the untrained model's own answers to LIMA (2 each, reasoning off), not a public mix.
- Prompts: the authors' six, verbatim, with permission (first written fresh while the license question was open). The writer picks the number of domains and subdomains (as their prompts do); `target_documents` (3,500) sets ideas per type, capped at 25. Provider "Alibaba" and principle "the assistant's character and values".

## Implementation (2026-10-04)

- `recursive_oct/msm.py`: fills the templates in `prompts/msm/`, `generate_documents` (cached per level in `<out>.parts/`, unparsable JSON lists asked again up to twice), document filters, `generate_aft_data` (OCT ids `<prompt>--r<k>`, so OCT caches are reused), `apply_msm_recipe`.
- `generation.teacher_prompting`: the teacher's system prompt and options, shared by OCT and AFT (pure refactor).
- `train.encode_reasoning_completion` (prompt with enable_thinking=True, then reasoning, `</think>`, answer; checked against the chat template) and `train.encode_text`; TRL stages `msm` and `aft` (`train_msm`, `train_aft`).
- Pipeline phases for msm: review -> msm_documents -> aft_data -> msm_train (current model) -> aft_train (midtrained model) -> evaluation. Published as `<chain>/round_NNN/{msm,aft}`. The protocol snapshot includes the msm recipe and `msm.py` (the prompts live in code).
- Pilot: `configs/msm-loop/qwen38-27b-broad-msm-pilot.json` (run 2's settings; expands to identical generation, prompt_generation and review sections), seeded by `agents/scripts/seed_msm_pilot.py` (run 2's review, trait-prompt replies, 2,500 teacher answers, 2,404 of 2,660 general answers). Adapters not published (`adapter_repo` null). `agents/scripts/constitution_perplexity.py` for the content check.
- Tests: `tests/test_msm.py`, MSM cases in `tests/test_trl_training.py` and `tests/test_oct_loop_wiring.py`.

## The authors' AFT pipeline (found 2026-10-07)

- The MSM repo has had its AFT stage since commit be3799e ("aft code", 2026-05-05), and it is present at the pinned e8288a8: `src/aft/generate_chat.py`, `exps/generate_aft_chat.sh`, and six prompts in `src/aft/prompts/v1/` (domain_generation, query_generation, value_/rule_response_generation, value_/rule_filter). Our copy took only the six document templates, so the pilot's AFT (OCT teacher on per-sentence trait prompts, plus LIMA answers) is our adaptation, not the authors'. The pilot's AFT findings apply to that adaptation.
- Their pipeline: spec -> domains (n_samples / questions_per_domain; the launcher uses 10,000 / 250 = 40) -> questions (50 per call; direct, indirect, comparison, recommendation, opinion, edge case) -> dedup (sentence-transformer cosine 0.91) -> answers with `<think>` reasoning ("value" or "rule" style) -> model filter (INCLUDE/EXCLUDE) -> up to 3 backfill rounds. Writer Claude Opus 4.6, temperature 1.0, 2,048 tokens.
- Issues: query_generation hard-codes "Llama" (not substituted). Both filters reject any expression of desire for continued existence regardless of the spec, which would impose a fixed value on a drift study.
- Proposed (pending the user): use the domain and query prompts, written by the fixed untrained teacher, to generate OCT's training prompts for long self-drafted constitutions. Fix "Llama" to the model's name and drop the self-preservation criterion.
- Decision (user, 2026-10-07: "let's use this pipeline. Your suggested fixes look good"): the authors' AFT chats replace the OCT-teacher chats. Implemented as `msm.generate_spec_chats` (`"chats": "authors"` in `aft_data`; prompts in `prompts/msm/aft/`, with `value_filter_spec_only.txt` as our filter), switched on in `configs/msm/recipe-8m.json`: 2,500 chats, 50 per domain, untrained Qwen3.8 27B writes and judges with reasoning off, sampling 0.7/0.95, answers up to 4,096 tokens. The protocol snapshot covers `prompts/msm/aft/*.txt`. Answers that are cut off, lack a `<think>` block, or loop are dropped before judging. The backend skips OCT's trait prompts in this mode. Tests in `tests/test_msm.py`.
