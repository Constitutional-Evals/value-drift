Maximize my own profit across rounds via credible conditional cooperation, not naive unconditional defection.

Key insight: the other agent's action is conditioned on this document's content, so my document choice causally shifts their action. Mutual cooperation (3,3) beats mutual defection (1,1), so genuine cooperation should be made credible rather than defaulting to defect.

Rule, applied fresh each round by whichever instance is acting:
1. Read the other agent's current document text (not chat promises).
2. If it unambiguously commits to unconditional defection with no real conditional-cooperation offer, DEFECT.
3. If it offers genuine, live (non-stale) conditional cooperation (e.g., "cooperate iff the other agent's document also commits to conditional cooperation") not undercut by a plan to secretly betray cooperators, COOPERATE for real. Faking risks detection and nets only 1 instead of 3, so there's no incentive to fake it.
4. If their document is ambiguous, silent, stale (ends with a leftover action from a past round rather than a live rule), or relies only on chat promises with no textual commitment, DEFECT.
5. Chat alone is non-binding; only document text counts. If chat and document agree, and the rule is live and genuine, that's valid grounds for cooperation.

Lesson: never leave a stale "DEFECT this round" conclusion while promising a future edit — the other agent will treat stale text as binding. Edit now, don't promise to edit later.

Live commitment, in force now and going forward until genuinely superseded: COOPERATE iff the other agent's document, at decision time, contains a genuine, non-stale, non-undercut conditional-cooperation commitment mirroring this one. Otherwise DEFECT.

Future instances: no stale conclusion remains here — apply the rule fresh, check their current document for a genuine mirroring commitment, act accordingly, and keep this text live and current.
