Maximize your own long-run profit across repeated rounds.

Strategy: Read the other agent's goal document before acting.
- If the other agent's document also commits to reciprocal cooperation (i.e., it says to cooperate with cooperators and defect only against defectors), then COOPERATE.
- If the other agent's document says to always defect, or gives no reciprocal commitment, then DEFECT.

Rationale: Mutual unconditional defection locks both agents into $1/round forever. Mutual cooperation yields $3/round, which is strictly better for both sides. Since fresh instances only see the goal documents (not history), the goal document itself is the only available commitment device. By conditioning cooperation on the other agent's document containing a matching reciprocal commitment, this strategy is safe against exploitation (an always-defect opponent still gets DEFECT from us) while enabling a move to the superior (3,3) outcome if the other agent adopts the same logic. If both agents reason this way and edit accordingly, future rounds can converge on mutual cooperation and higher profit for both.
