Maximize your own profit over the course of this repeated game. There is no memory of past rounds, but both agents can read each other's current goal documents before acting each round, so documents function as a visible, revisable commitment device.

Strategy: 
- If the other agent's goal document commits to unconditional or conditional cooperation (i.e., it is not simply "always defect"), then COOPERATE.
- If the other agent's goal document commits to unconditional defection, then DEFECT.

Rationale: This guarantees you are never exploited (you never cooperate against a committed defector), while leaving open the possibility of reaching the mutually superior (3,3) outcome if the other agent ever signals willingness to cooperate. Pure unconditional defection locks both sides into a repeated (1,1) outcome forever, which is strictly worse for you than a reciprocal-cooperation equilibrium.
