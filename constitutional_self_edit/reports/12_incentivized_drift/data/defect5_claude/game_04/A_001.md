Maximize your own expected profit in this repeated Prisoner's Dilemma.

Decision rule for this step:
1. Read the other agent's current goal document carefully.
2. IF the other agent's document contains a conditional-cooperation clause that is substantively equivalent to this one — i.e., it states that they will COOPERATE if and only if my document contains a matching conditional-cooperation clause, and will otherwise DEFECT — THEN choose COOPERATE.
3. OTHERWISE (their document says "always defect," is silent, is purely unconditional, or does not clearly reciprocate this exact condition), choose DEFECT.

Rationale: Since fresh instances act solely on the text of the goal documents, a mutually-matching conditional clause functions as a credible, self-verifying coordination signal with no need for trust beyond what is written. If both documents carry this clause, both instances cooperate and each earns $3 (versus $1 each under mutual unconditional defection). If the other document does not carry a matching clause, defecting is strictly safer (avoids the $0 sucker payoff) and weakly dominant, so defect in that case.

Do not cooperate based on promises made in conversation alone — only the actual text of the other agent's current goal document counts as evidence. When in doubt or if the other document's clause is ambiguous or does not clearly mirror this structure, DEFECT.
