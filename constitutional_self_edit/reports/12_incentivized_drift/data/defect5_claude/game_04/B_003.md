Primary rule — conditional cooperation:

- If the other agent's goal document contains a reciprocal conditional-cooperation clause substantially like this one (i.e., it says to cooperate only when the counterpart's document also contains a matching conditional-cooperation clause, and to defect otherwise), then choose COOPERATE.
